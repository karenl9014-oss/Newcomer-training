# 不會寫程式？那就魔法詠唱吧！

新人實作課程的獨立預覽版，共 13 頁。課程時間可依現場節奏調整。

## 開啟方式

直接以瀏覽器開啟 `index.html`。這是完整單檔版，已內含樣式、互動程式與圖片，不需要一起攜帶其他檔案。

## 操作

- 使用左右方向鍵或右下角按鈕切換頁面。
- 第 4 頁可查看模糊需求的示範結果。
- 第 5 頁保留六項「需求詠唱強化器」互動。
- 第 6、9、10 頁提供回饋、實作成果與人工驗收互動。
- 已保留「為什麼要部署」與課後禮物頁，供講師依現場流程使用。
